# 当前最大瓶颈（2026-11-13 07:15）

## chopTree 走不到树 —— 85% 的失败都源自这一条

### 完整失败链（实测复现）

```
没有镐子
  → 要木头做镐
    → chopTree 走不到树（差 6.1 / 5.2 / 4.3 格，连续刷）
      → 砍到 0 棵
        → 做不出木镐
          → 挖不了石头（没镐子挖石头不掉东西）
            → 圆石 0 → 做不出石镐 → 放不了箱子 → 存不了东西
```

### 隔离实测数据

```

[tool] 备木头第 1 轮（现有原木 0、木板 0）
[chop] 走不到这棵（差 6.1 格），换下一棵
[chop] 走不到这棵（差 5.2 格），换下一棵
[chop] 这一圈都砍不动，往外走
[chop] 走不到这棵（差 4.3 格），换下一棵
[chop] 只砍到 0/1 棵，时间/可达性限制
```

`mine('stone',3,24)` 在无镐时耗时 **246 秒**并失败。

### 已经做过的尝试（都失败了）

`chopTree` 里有 `standSpotsNear()`，处理了三件事：
1. 目标不能设成树干本身（实心原木，A* 找不到落脚点）
2. 候选格覆盖树干 y±5 高度范围
3. 优先选跟 bot 高度接近的位置

**但还在差 4-6 格。** 说明还有没覆盖到的情况。
