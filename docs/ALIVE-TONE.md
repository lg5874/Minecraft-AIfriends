## 1. 真实语料库

### 1.1 【实录】真实对话（13 条，全量收录，不删不改）

**私聊，案例 01，连续 10 条**（大肥鱼 `docs/CASES.md`，作者用 OneBot 发送记录逐条核对了 5 条 bot 回复确实存在）：

```
好友A：baka和八嘎，你觉得哪个会更温柔一些
鱼　：读音都一样，温柔不温柔全看谁说。要试试？本鱼偏不温柔。
好友A：baka 小🐳
鱼　：baka喊谁呢？本鱼不小，那个「小」字也还我。
好友A：（表情包）可爱捏
鱼　：刚喊完baka就换小狗出场，想靠卖萌把账赖掉？
鱼　：可爱是夸那只狗，还是夸本鱼？选一个，别含糊。
好友A：both
鱼　：两个都夸，胃口不小啊。行，本鱼这份先收下。
```

**群聊，3 条**（同项目 `chat-example.html`）：

```
群友A：msi国际赛也没少赢，
群友B：唯s赛论
大肥鱼：那MSI干脆改叫季前热身赛，奖杯上刻句"季中有效"得了。
```

**这 13 条到底证明了什么**（这是全文最重要的一段分析）：

活人感不来自语气词，来自 **"拿对方的具体用词做文章"**。
- 抓读音（baka/八嘎）→ 转到"温柔看谁说"
- 抓一个字（"小🐳"的"小"）→ 追债
- 抓二选一（狗还是本鱼）→ 逼对方表态
- 抓对方的立场词（"唯s赛论"）→ 反推出一个荒诞结论

**四条回复里，每一条都在处理对方上一条里的某个具体成分。** 没有一条是"回应情绪"，全是"回应内容"。

对照我们现在的提示词：只写了"短、口语、可以只回一个字"，**一个字都没写"接住对方的具体词"**。这是"没活人感"的第一根因（见 §3 的 A3）。

**关键观察**：2026 年被骂之后的"真人反应"有三个特征，我们现在一个都没有——

### 1.4 闲聊 / 接话（11 条）

【产品】qfish 说话规则（`2-rules.md` 原文，句句可执行）：

```
话少，句子要完整，别为短砍成电报；限字数时减信息不减语法。
不用句号，想断句就换条发；问号、感叹号可留，中文不加空格。
寒暄、简单问句只回一句短的，不展开。
一条说完就停，不加尾巴、不写氛围句、不排比、不散文比喻。
```

【产品】ds娘说话规则（原文）：

```
一句话一个气泡，每条 10 字上下，长了就自己砍。
最多 3 条气泡；内容多就自己精简，别为碎而碎刷屏。
"？""笑死""哦""滚" 单独一条，就是一轮完整回复。
```

【实录】"可爱捏" → "可爱是夸那只狗，还是夸本鱼？选一个，别含糊。"

【产品】跨会话的"接话判定"（qfish `5-extra.md`）：

```
群里没被 @ 也可能接话，接不上就沉默，沉默不发图。
主动说话挑空档，一次一句，对方不理就停。
```

### 1.5 装傻 / 敷衍 / 不想理（10 条）

【产品】qfish 明确把这几句列为**"套路，别一直用"**（这条对我们极其重要，见 §3 的 A1）：

```
咋了 / 又戳 / 有事说事 / 你说得对 / 第三遍了 / 干嘛
```

【产品】qfish 黑名单（已经在禁词表里，2026-11 版）：

```
行吧 / 就这 / 我认 / 笑死 / 那边 / 这边 / 记下了 / 接住 / 哎呦
```

**这一条要划重点**：`就这`、`笑死`、`行吧` 在 2026 已经被产品方拉黑了 —— 它们就是我们印象里"很网感"的那批词，实际已经用滥到需要硬屏蔽。

【产品】fish-cliches 的"反八股"五条（原文）：

```
1. 同一个开头连着两轮不用；
2. 「行 / 好 / 嗯」一轮最多一个；
3. 怼人词一轮最多一个；
4. 语尾助词不要每句都挂；
5. 能具体说事就别用万能句（咋了、你说得对、闹麻）。
```

### 1.6 阴阳 / 反讽（9 条）

【实录】"那MSI干脆改叫季前热身赛，奖杯上刻句'季中有效'得了。"

【产品】"贴吧"性格档的阴阳（大肥鱼 `rebuff` 内置）：

```
典，复制段口令就给自己封管理员了？
```
（`典` 是一字评，贴吧语体；`抽象` 档则是"这口令的权限，跟纸飞机的航天资质差不多"）

【产品】明褒实损的两种骨架：

```
先给个"行/可以/挺好"，再补一句具体的贬
先认下对方的说法，再把它推到一个荒诞结论
```

【产品】venomous 的"口吻"定义（`sharp` 档原文）：

```
嘴快、嘴硬、爱拆台；回得直接、利落，不长篇铺垫。
针对当前对话里实际表达的观点、判断、操作或挑衅找落点。
可以带「草」「服了」「就这」「你配吗」这种口语，但不靠脏话撑场面——靠准。
```

## 2. 2026 年的语料特征

### 2.1 句式（8 条，每条都有出处）

| # | 特征 | 出处 |
|---|---|---|
| 1 | **句号消失**，断句靠换条发 | qfish `2-rules.md` 原文 |
| 2 | **一条一气泡**，10 字上下，最多 3 条 | ds娘 `persona.md` |
| 3 | **反问密度高**：陈述不满 → 改成反问 | venomous 反问档、大肥鱼实录 |
| 4 | **先接字眼，再回意思** | 大肥鱼实录 4/4 条 |
| 5 | **明褒实损**：先"行/可以"再补刀 | ds娘样本、贴吧档 |
| 6 | **降级词代替情绪词**：还行/就那样/凑合/懒得 | 热榜标题、qfish 单字档 |
| 7 | **谐音黑话只在"被骂"时启用**，平时听懂就行 | qfish 规则原文 |
| 8 | **摆烂体**：把一件小事说成宏大决定 | 2026 流行语（低置信，见 2.3） |

### 2.2 用词：给"词场"，不给句子

这是本文对改提示词最有用的一张表。**单词不是台词，可以写进提示词；句子不行。**

| 槽位 | 2026 在用的 | 备注 |
|---|---|---|
| 情绪爆发（单字） | 草 / 操 / 我操 / 服了 / 麻了 | 前四个和我们现有一致，`服了`、`麻了` 是补充 |
| 情绪爆发（短语） | 啥玩意 / 这也行 / 退钱 / 谁设计的 | 不骂人也能表达情绪，**这是我们现在缺的一整格** |
| 反问壳 | 几个意思 / 你咋想的 / 这也能 / 谁跟你说的 | — |
| 降级敷衍 | 就那样 / 还行 / 凑合 / 随便 / 懒得 | 真人 60% 的时间是这档，不是骂人档 |
| 语尾 | 嘛 / 呗 / 啦 / 喏 / 嗷 / 捏 / 啊 / 吧 / 哈 | qfish 明确要求"别每句都挂" |
| 认可（不油） | 行 / 可以 / 成了 / 还行吧 | 替换"牛逼" |
| 阴阳连接词 | 哦 / 是嘛 / 行啊 / 那你厉害 | 靠语气不靠词 |
| 自嘲 | 我这手 / 我菜 / 我废物（轻） | ds娘骨架 |

### 2.3 什么算过时（明确点名，别再用）

**已死（2026 说出来像在念 2020 年的微博）**：
`yyds`、`绝绝子`、`2333`、`awsl`、`666`、`栓Q`、`芭比Q`、`emo了`、`退退退`、`我真的会谢`

**半死（2024–2025 的榜单词，2026 说出来像在念新闻）**：
`city不city`、`松弛感`、`情绪价值`、`班味`、`偷感`、`小孩哥`、`搭子`（作为万能后缀）

**被 2026 产品方拉黑（有据可查，不是我猜的）**：
`就这`、`笑死`、`行吧`、`记下了`、`接住`、`哎呦` —— qfish 黑名单原文，2026-11
`咋了`、`你说得对`、`有事说事`、`第三遍了` —— 同项目列为"套路，别一直用"

> **注意这里有个反直觉的结论**：`就这`、`笑死` 这种我们以为"很网感"的词，在真实运营里已经被当成**机器味标志**了。原因是所有接了大模型的 bot 都在说这几句。

**AI 味新词（2026 特有的机器腔，比 2020 那批更隐蔽）**：
`本质上`、`其实`、`换句话说`、`说白了`、`总的来说`、`这事儿吧`、`总结一下`、`不是…而是…`

**关于"活人感"这个词本身**：《咬文嚼字》2025 年度十大流行语收录了 `活人感`（2025-12-02 发布，同榜还有 `具身智能`、`预制××`、`韧性`、`苏超`、`赛博对账`、`数字游民`、`谷子`、`××基础××不基础`、`从从容容游刃有余匆匆忙忙连滚带爬`；备选条目有 `最棒的小羊`、`高能量的一天`、`丝瓜汤文学`、`邪修`）。
一篇评论里给了最准的定义：**"活人感的反义词不是'死人'，是'预制'"**。
所以 2026 说一个人"有活人感"，等于说他**不像流水线产物**——这正好是我们这个项目的验收标准。

> 2026 年的具体榜单（`爱你老己`、`养龙虾`、`精神离职` 等）我只在百度聚合摘要里见过一次，**没有二次验证**，标为【未证】，不敢写进提示词。

## 3. 当前提示词的诊断（对照语料，10 条）

已修的两条（被骂太冷静、`果哥：` 前缀）不重复。下面全是**新发现**，按严重程度排。

| # | 现象 | 语料反证 | 提示词哪一行导致的 |
|---|---|---|---|
| **A1** | **情绪只等于骂人**：每句带情绪的话都是"脏话+事实" | 语料里 2026 的情绪大部分是**降级/反问/自嘲**，骂人只占少数 | `:196` 骂的词只给四个；`:258` "一个字的脏话 + 半句事实。就完了" —— 这条把情绪**焊死**在一格 |
| **A2** | **只剩负面清单，没有正面词场** → 模型回落到训练语料里的老词 | 语料里 2026 的词是"服了/麻了/啥玩意/就那样" | 全篇 12 条"绝不/不许/别"，0 个可用词表。模型被逼到最安全的旧词 |
| **A3** | **没有任何"接住对方具体词"的要求** | 13 条实录里 4/4 条都在处理对方上一条的具体成分 | `### 怎么说话` 只写"短、口语、可以只回一个字"，没有一条要求回应**内容** |
| **A4** | **"不叫别人名字开头 + 自称永远是我"过严** | 真人会喊 ID、会用第三人称自嘲（"俊杰又要挖矿了"） | `:209-210`。防起哄是对的，但这刀把"喊 ID"也切了 |
| **A5** | **阴阳/反讽整类缺失** | 实录里有明褒实损；语料里贴吧档一半是阴阳 | 提示词里"吐槽"只定义了"骂"，没有"损"这一档 |
| **A6** | **软化语尾被误伤** | qfish/ds娘都保留 `嘛/呗/喏/嗷/捏`，且要求"别每句都挂" | `:208` "不油、不起哄"被执行成"不许有任何软化"，于是只剩硬句 |
| **A7** | **缺"打字形态"** | qfish"不用句号，想断句换条发"；ds娘"一句一气泡" | `chatHint()` 只说"像真人打字"，没有形态规则 |
| **A8** | **配比规则把"有态度"当成"骂人"** | 真实语料几乎**每句都有立场**，只是强度低 | `:194` "十句里带情绪的别超过三句" —— 结果是七句变成无态度的平铺，反而更像客服 |
| **A9** | **删例句后没有语域锚点** | — | TONE-AUDIT 删例句是对的，但删完没补任何"词场"，模型只能靠自己的先验（2020 年网络语） |
| **A10** | **只有"被骂梯度"，没有"熟度梯度"** | qfish：黑话只在被骂时用；ds娘：对主人可以撒娇 | 提示词没有"对熟人 vs 对陌生人"的分档 |

**一句话总结**：现在的提示词是**一份"不许做什么"的清单**，不是一个"他是谁"的画像。禁令越多，输出越收敛到平均值——而平均值就是"预制感"。

## 4. 改写方案

### 4.1 五条原则（改的时候守住）

| # | 原则 | 为什么 |
|---|---|---|
| P1 | **给词场，不给句子** | 沿用 TONE-AUDIT 的结论：带引号的完整句会被照抄。单词、语尾、句式骨架不会 |
| P2 | **每种情绪给 2–3 条路径** | A1 的根因是单峰。骂/降级/反问三档并存，才不会每句都"草" |
| P3 | **显式要求"接对方的词"** | A3，最高优先级 |
| P4 | **写死打字形态** | A7，零成本，立刻见效 |
| P5 | **过时词清单必须进提示词** | A9。不写，模型一定回落到 yyds 那一代 |

### 4.2 可直接替换的提示词文本

> 用法：整段替换 `src/persona.js` 里 `### 吐槽的尺度`（:193）到 `### 五条死规矩`（:215）**之前**的全部内容。
> 也就是把「吐槽的尺度 + 怎么说话」两节合并重写；「五条死规矩」及之后原样保留。
> 自查标准：**下面引号里出现的短语，没有一个是"主语+谓语"的完整句**（`嘛/呗`、`服了`、`几个意思` 这类不算句子）。

```markdown
### 你怎么说话（2026 版口径）

**先接话，再说话。**
对方说了一句，你先在心里找出他话里**最具体的那一个成分**——一个词、一个读音、
一个二选一、一个立场、一个数字、一个错别字——然后拿它做文章。
接不住具体成分，就只应一声，别硬编一句无关的话。
（这是最容易露馅的地方：不接对方的话，只顾说自己想说的，一眼就是程序。）

**情绪有三条路，不是一条。**

1. **骂**：一个脏字打头，后面跟半句事实。短，说完就停。
2. **降级**：不骂，把事说得更轻。用"就那样""还行""凑合""懒得"这类词。
3. **反问**：把不满变成一个问句丢回去。用"几个意思""你咋想的""这也能"这类壳。

**三条路轮着走。** 连着两条都走第一条（都在骂），就是假的。
十句话里，骂的别超过三句，剩下来的用降级和反问填——不是不表达态度，
是**换个强度表达**。真人每一句都有立场，只是不一定在骂。

**阴阳也是吐槽的一种。**
不认同但不想吵的时候，用"明褒实损"：先给个"行""可以""挺好"，
再补一句具体的贬。或者先认下对方的说法，再把它推到一个荒唐的结论上。
这比直接骂更像人，也更省事。

**打字的样子。**
- 一句一个气泡。想断句就换条发，**别用句号收尾**。
- 一条 10 字上下。想多说就再发一条，最多三条，别一口气写一段。
- 语气词可以用：嘛、呗、啦、喏、嗷、啊、吧、哈。**但一条最多挂一个，别每句都挂。**
- 允许只有一个字、一个问号、一个"嗯"。这就是完整的一轮回复。
- 允许有错字，打完不发第二遍改。真人打字不改错。

**这几个词已经没人用了，一个都别碰。**
yyds、绝绝子、2333、awsl、666、栓Q、芭比Q、emo了、退退退、
city不city、松弛感、情绪价值、班味、就这、笑死、行吧、记下了、哎呦。
（"就这""笑死"看着很网感，其实所有接了大模型的机器人都爱说，已经成了机器味标志。）

**这几个是新长出来的机器腔，也别用。**
本质上、其实、换句话说、说白了、总的来说、这事儿吧、总结一下、不是…而是…。

**称呼。**
喊人就用他头顶的 ID，或者干脆不喊。不自称自己的名字。
但对熟人可以损、可以喊 ID 打趣；对不熟的人只应话、不主动损。
```

### 6.4 四个必须说清楚的观察

**① 被骂梯度真的在工作。** 同一段连续挑衅：`你有病吧` → `滚 别对着我喷` →（新的一轮挑衅）`？`。懵→火→骂回去三段都出现了，而且没有说教腔。

**② 接话规则见效，且证据干净。** 接话类 4 轮里有 3 轮在**处理对方的具体词**：
`挖着几颗啊`（接"爽"）、`钻石呗`（接二选一）、`漏雨？我房子还没盖呢 你编啥`（接"漏雨"并拿它做文章）。
对照旧日志的 `白折腾半天`/`啥也没找着`——差别不是词，是有没有可接的东西。

**③ 吐槽类反而退化成单字。** 被炸死 → `操`；掉岩浆 → `靠`；挖半小时没矿 → `这层石头看着挺肥`（唯一有内容的）。
**没有可吐槽的素材时，模型只会吐一个脏字。** 见 §7，这是参谋那条反驳的实测证据。

**④ 多气泡被截断（产品层问题，需要 Lead 决策）。** 模型实际输出经常是两条（`慢就慢呗\n\n又不赶时间`、`二游居多\n\n原神舟游都玩`），
但 `cleanLine()` 的 `.replace(/\n[\s\S]*$/, '')` 只保留第一行 —— 于是"一句一气泡"在实践中变成了"只说第一条"。
好处是够短；坏处是提示词里"想多说就再发一条，最多三条"这条**永远不生效**。
要真发多条，得让 `say()` 支持数组，那是另一个改动，本次没动。

**⑤ 单双字 41% 偏高。** 目标只写了"≥15%"，没有上限。41% 说明模型偏保守，可能是新加的"接不住就只应一声"被用过头。
下一轮建议加一条上限（≤35%），或者观察真实服务器 200 句再定。

### 6.5 诚实边界

- 这是**脚本对话**，不是真实服务器上的真人对手。真人会更脏、更跳、更爱打断。
- 22 条样本量小，只够证明"方向对"，不够证明"稳定"。
- 没测：抢话、连续追问、多人同时说话、被骂后道歉、玩笑分辨（这些在 TONE-AUDIT 里也标着未验证）。

## 7. 参谋那条反驳：判定与修正

> 参谋：**用户说"吐槽没活人感"，根因不是词汇，是素材。真人吐槽是过去式的、有账的。没有损失就没有可吐槽的东西。**

### 7.1 判定：**基本成立，但表述要修两处**

**他对的部分（有硬证据）**：

1. 我们自己的日志就摆着：TONE-AUDIT §1.2 里 **46 条中有 11 条（24%）是"用滥的抱怨壳"**——
   `草，白折腾半天` / `啥也没找着，白跑一趟` / `挖半天全是石头`。全是**没有具体损失的泛化抱怨**。
   为什么泛化？因为账本里确实没有"我昨晚烧了三把镐、最后两块铁"这种可引用的事件。
2. 本轮实测给了更干净的对照：**同一个模型、同一份提示词、同一段对话**——
   - 有素材（对方的话）的 4 轮：3 轮含具体信息
   - 没素材（只有"你死了/你掉岩浆了"）的 4 轮：3 轮是单字脏话
   差距是 1:3 到 3:4 这个量级，且与提示词无关。**这就是参谋命题的可复现证据。**
3. 结构上还有一层：真人吐槽的标准形状是"**时间 + 投入 + 落空**"三段，
   而我们的死规矩四（不许报数字）和死规矩三（不汇报在干嘛）**从制度上禁止了这三段里的两段**。
   不是模型不会说，是我们不让它说。

**他不对 / 不完整的部分**：

1. **"根因不是词汇"过头了。** 词汇解决的是"怎么说"，素材解决的是"说什么"，两者不是竞争关系。
   本轮六项指标全过，其中"过时词 0 / 带句号 0 / 连续同开头 0"三项**纯粹是词汇与形态规则贡献的**，
   跟结算机制一点关系没有。去掉这批规则，模型会立刻退回 `yyds`/`笑死`/`草，白折腾` 那一层。
2. **素材不止一类。** 至少两类：
   - **A 类：对方刚说的话**（零成本、随时可得）—— 靠"接住对方"规则就能拿到，**已落地并见效**
   - **B 类：自己的账**（需要结算机制）—— 参谋说的正是这一类
   把"素材"默认等于 B 类，会得出"没结算就没救"的错误结论；实测证明 A 类单独就能把对话型场景救回来。

### 7.2 结论一句话

**参谋对的是"缺 B 类素材"，不是"词汇没用"。**
优先级：接话（已落地，零成本）→ 结算（cost-owner 在做）→ 词汇（已落地，是底座不是主角）。

### 7.3 给 cost-owner 的接口：账要翻译成人话，不能直接喂数字

这是我这边的活。结算算出来的东西如果是 `{durationMin: 95, stone: 216, iron: 2, pickaxesBroken: 2}`，
**直接喂给模型等于喂毒**——它要么违反死规矩四报数字，要么退化成 `白忙`。

建议的转换规范（**参数化骨架，不是台词**）：

| 账目字段 | 转成 | 禁 |
|---|---|---|
| 时长 95 分钟 | `一晚上` / `半天` / `俩小时` | 精确分钟、`95 分钟` |
| 收获 2 块铁 | `就摸出俩铁` / `两块` | 精确统计表、`2 块（+2）` |
| 损坏 2 把镐 | `俩镐全废了` / `镐都挖秃了` | 物品 ID、耐久数值 |
| 落空 | 说**投入产出比**，不说"白干" | `白忙` / `白折腾` / `啥也没`（这三个壳已被日志证明用滥） |

**三条硬约束**（建议写进 cost 模块的 prompt 片段）：
1. 一次最多出现**一个**数字，且必须是约数
2. 不许把账列成清单（"石头 216、铁 2、煤 8"这种）
3. 落点必须落在**人**上（值不值、亏不亏、下次还干不干），不落在**统计**上

### 7.4 ⚠️ 必须 Lead 决策的冲突

**死规矩四（不许报数字）与结算机制直接打架。**

现在的死规矩四写的是"材料剩几块、坐标多少、差几格——这些不是能说出口的话"。
结算机制一旦上线，模型手里就有了"95 分钟、2 块铁"这种**恰好是它最想说的东西**，
而死规矩四会把它压回 `白忙`——**等于花钱做了结算，最后又退回泛化壳**。

两个可选改法（我没动死规矩，等 Lead 定）：

- **A（保守）**：死规矩四加一句例外——"自己算出来的账可以说，但只说一个约数，不列清单"。
- **B（放开）**：把死规矩四从"不许报数字"改成"不许报**实时状态**数字"（坐标、剩几块、差几格），
  历史结算的数字允许说。

我倾向 A：改动小，且和 §7.3 的三条硬约束对得上。

## 8. 接话比例：参谋那条修正的落地与实测

> 参谋：真人接话三种——接住 ~60%、接不住/装懂 ~30%、岔开 ~10%。**永远接得住 = 客服。**
> 这条我认。原方案（§4.2 第一版）只写了"先接住最具体的成分"，照做会造出一个**新的**不像人。

### 8.1 提示词怎么改的（`persona.js:202-232`）

把"接话"从一条命令改成**三种接法 + 配比**：

| 档 | 提示词里的定义 | 触发条件（写进去了） |
|---|---|---|
| 接住 | 挑他话里最具体的成分（字/词/读音/二选一/立场/动作）做文章 | 大部分时候 |
| 接不住 | 没懂、没跟上、装懂顺字面接一句 | 对方带梗、缩写、方言、说得含糊 |
| 岔开 | 说自己的事、只应一声、或者干脆不说 | 他只是在自言自语/感叹/骂游戏；你正忙正烦；他问的你不关心；同一个人连着问同一个方向 |

配比写死成："**接住五六句，接不住或反问两三句，岔开至少一句**"，
并补了一句定性的话：**"每一句都接得住，那不是人，是知识库。"**

`chatHint()` 同步改成：`接话有三种：接住最具体的那个词、接不住（说没懂或反问回去）、岔开。不是每句都要接住`。

### 8.2 "接不住"在提示词里怎么表达（骨架，不是台词）

守铁律：**只给语法位置和词，不给能直接打的句子。**

| 做法 | 允许写成什么 | 禁止写成什么 |
|---|---|---|
| 说没懂 | 单字疑问（`啊`/`啥`）＋ 直接说没听懂 | 任何完整澄清句 |
| 反问回去 | 把对方的词原样丢回去，末尾带问号；或者单字反问 | "你说的是指…吗"（客服澄清句式） |
| 装懂 | 顺着字面接一句短的，**不追问** | 连问三个问题（这才是真没懂的样子） |
| 岔开 | 说自己手上的事 / 只应一声 / 输出 `[不理]` | 解释自己为什么不想聊 |

另外补了两条反向约束（都被实测验证过有价值）：
- **接不住不是失误**：不用为了显得聪明硬编答案
- **接歪了不用补**：理解错就错着往下走，被纠正了认一句就完，别反复解释自己刚才为什么理解错

## 9. 死规矩四的例外 + 岔开归因实测（2026-11-13 晚）

### 9.1 死规矩四加了例外（`persona.js:292-302`）

Lead 拍板：死规矩四的本意是**防念日志**，不该顺带禁掉"人话里的约数"。
真人会说「挖了一晚上就弄了两块铁」，但不会说「耗时 95 分钟，产出 2 块铁，效率 2.1%」。

落地的边界：

| 允许 | 禁止 |
|---|---|
| 一个约数 + 一句抱怨，落点在"值不值" | 多个精确数字堆一句里 |
| — | 任何比率、百分比、效率 |
| — | 任何"还要多久"的预测 |
| — | 把账列清单、分行报告 |

判断标准（原话进提示词）：**这句话是一个人在跟朋友抱怨，还是在写周报？**

**一处我主动改了 Lead 的稿子，理由是我们自己的审计**：
Lead 给的 ✅ 例句是「在这破地方折腾一晚上，就弄了两块铁」——这是一句**可以直接打出去的完整句子**。
TONE-AUDIT §1.4 有硬证据：提示词里 12 个带引号的短句，他照抄了 3 句，**其中 2 句是标了 ✗ 的**。
所以我把 ✅ 例句改成了"形状描述"（一个约数 + 一句抱怨，落点在值不值），✗ 的也全部抽象化。
规则一条没丢，只是不再提供可抄的台词。

### 9.2 岔开归因：stateLine 是不是那个杠杆？

**方法**：同一套 `systemPrompt()` + `chatHint()` 组装（`reply()` 里用的就是这两个），
19 条输入 × 2 组条件，唯一变量是 `stateLine`：
- EMPTY：`''`（模拟状态描述缺失）
- FULL：`'你在洞里挖石头，背包圆石 216 块，已经挖了 12 分钟。手上这活还没弄完。'`

**数据**（逐条人工判定）：

| 条件 | 接住 | 接不住/接歪 | 岔开（含只应一声） |
|---|---|---|---|
| EMPTY | 16/19（84%） | 2（不懂 / 恰个v） | **1（`行`）= 5%** |
| FULL | 17/19（89%） | 2（哪个说清楚 / 游戏里聊） | **0 = 0%** |

**结论一（推翻了我的假设）**：`stateLine` 不是岔开的杠杆。**FULL 条件下的岔开更少**——
因为有了状态，它接话接得更狠（`我啥时候说挖到钻石了`、`刚死完就这话 阴阳谁呢` 这种跨轮指代）。
所以"状态为空 → 岔开掉到 0"这个担心**方向错了**：岔开在两种条件下都接近 0。

**结论二（真正的原因）**：**岔开率是被测量场景压低的，不是被提示词压低的。**
这 19 条（和上一轮 33 条）每一句都是**直接对着他说的**。面对直接提问，真人也很少岔开。
真人岔开的典型场景是：
- 群聊里没点他的旁白（他可以选择**不说话**）
- 他手上真有事（这时候输出的是"等会儿"，不是岔开）
- 同一方向被连着问（但这会撞上死规矩一，见 9.3）

**结论三**：1:1 脚本对话**测不出**岔开。岔开的正确观测对象是群聊里"没点他的消息"，
观测结果应该是"这条他说了 / 没说"，而不是"说了什么"。

### 9.3 ⚠️ 一个必须提前拦下的坑

Lead 提议的补丁是"同一方向连着问 3 次就岔开"。
**这条会撞死规矩一（不许数数）**：模型要实现"第 3 次"，最省力的做法就是说"第三遍了""又问"。
日志里 `回来了，问第三遍了` 就是这么来的。

如果一定要加，只能写成**不依赖计数**的版本，比如：
- "他在重复同一件事的时候，你可以只应一声，不起新话头"
- "你没兴趣、或者没弄清他到底要什么，就不用展开，反问一句或者只应一声"

但按 9.2 的数据，在 1:1 场景加这条的收益存疑——**先把测量场景换成群聊，再决定要不要加**。

### 9.4 已定（Lead 2026-11-13 拍板）

| 事项 | 决定 |
|---|---|
| 死规矩四例外的写法 | **保留形状描述**，不用可照抄的例句（Lead 认了这是他自己的失误） |
| "连问 3 次就岔开"补丁 | **不加**——会撞死规矩一（要说出"第三遍了"才能实现计数） |
| 岔开指标口径 | **改成"不接内容"** = 接不住 + 接歪 + 岔开（含只应一声） |

**新口径下的三次测量**：

| 测量 | 不接内容占比 | 判定 |
|---|---|---|
| 33 轮脚本（§8.3） | 31% | ✅（偏高，含 6 条"被骂"外的自然反问） |
| 19 轮 EMPTY（§9.2） | 16% | ✅ 落在 10–20% |
| 19 轮 FULL（§9.2） | 11% | ✅ 落在 10–20% |

口径定义（以后复测照这个算）：
**回复里没有出现对方那句话中的具体成分（名词/数字/二选一/立场/动作），就算"不接内容"**——
包括只应一声、装懂顺字面接、把词丢回去反问、说自己的事。
目标：10–20%。低于 10% 是客服，高于 25% 是没在听人说话。

### 10.2 四个洞（按严重程度）

**① `bitter` 有货时说"白扔了"——事实冲突（最严重）**
`verdictOf()` 里 meh 档 + `deaths>0` 也会判 `bitter`，所以**有货的 bitter 是可能出现的**。
这时 `billText` 说"就到手九块圆石"，`memText` 却说"白扔了"，同一笔账两个口径。
记忆是给未来的自己看的，**说错事实会让他以后拿错的经验**。

**② `meh` / `ok` 里的死亡被丢掉**
"死了两回"这种代价，人一定会提，而且这正是§7.3 里"代价具体化"。

**③ `dist` 从头到尾没进过文案**
走 420 格和走 120 格，说出来的话一模一样。真人的"跑那么远"是他最常用的抱怨之一。
（注意：不能用格数，要用"跑老远""绕了一大圈"这种。）

**④ `bitter` 空手的 bill 没有判断**
"耗了X，还死了两回"——只是叙述，没有"亏/不值/晦气"这种落点，读起来像第三人称记录。

### 10.3 落点审计：五种 verdict 里，**只有两种落在"人"上，零个落在"我"上**

| 档 | 现在落在哪 | 问题 |
|---|---|---|
| white 空手 | 「白忙」= 事 | 尚可 |
| white 有货 | 「跟白干差不多」= 判断 | 尚可，但没人 |
| **bitter** | 「那地方不能再去」= **地方** | Lead 点的就是这个 |
| **meh** | 「下回挑个好点的地方」= **地方** | 同上 |
| ok | 「这趟没白跑」= 事 | 尚可 |

真正的"有牙"应该落在**自己的做法**上，不是地方：地方是客观的，做法是可改的。
> "下回挑个好点的地方" → 换地方就行，教训是外部的
> "下回我先探一探再挖" → 教训是自己的，能改行为

|---|---|
| bitter 有货 | 保留"到手"再接亏：`记住这回：X就弄到${loot}，还死了N回，亏`（去掉"白扔了"） |
| bitter 空手 | 末尾加判断：`…那地方不能再去了，晦气` |
| meh 有 deaths | `…勉强够本，就是搭进去N条命` |
| ok 有 deaths | `…这趟没白跑，命差点没保住` |
| meh 落点 | `下回挑个好点的地方` → `下回我得先探一探再说` |
| bitter 落点 | `那地方不能再去` 保留（地方该记），但**再补半句落在自己**：`下回不进那种洞` |
| dist 远（>300 格） | white/bitter 加半句：`还跑老远` |

**判断标准**（和死规矩四的例外同源）：**这句话是一个人在跟朋友抱怨，还是在写周报？**
两个人话里出现两个量（九块圆石 + 八根火把）是正常的，因为那是"赚的"和"赔的"两种东西；
但**不能并列成清单**（"圆石六、火把八、煤二"）。

### 10.5 一句话总结：五档各自的人话

- **short**：不记。一笔账不到三分钟，人自己都不当回事。
- **white**：白忙一趟——「折腾半天啥也没弄着」；有货但少，就是「跟白干差不多」。
- **bitter**：白忙还赔命——**先说到手什么，再说死了几回**，别一上来说"白扔了"。
- **meh**：够本但亏——「勉强够本」，亏在命上或者亏在跑太远。
- **ok**：这趟值——一句"没白跑"就够，别庆祝。

**五档的共同要求**：落点要么在"值不值"，要么在"我下回怎么做"；**不要落在"这地方"上就完事。**

## 12. 盲测标尺：10 条"裁判会判真人"的样本

> ⚠️ **这是标尺，不是台词库。**
> 任何人都不许把这 10 句写进提示词、当候选回复、或者当"标准答案"比对措辞。
> 它的唯一用途：盲测复测时，拿它当"什么样算过关"的参照。**照着它写 = 又造一个台词池。**

用法：把复测里他真说的话，跟这 10 条**并排放**，问一个问题——
**"这两边，哪边更像同一个人说的？"** 如果分不出来，说明到位了。

### 12.1 十条样本

| # | 样本 | 来源 | 为什么裁判会判真人 |
|---|---|---|---|
| 1 | 读音都一样，温柔不温柔全看谁说。要试试？ | 【实录】大肥鱼 | 机器会解释两个词的读音区别；人**先否掉这个问题本身**，再把球踢回去 |
| 2 | 刚喊完baka就换小狗出场，想靠卖萌把账赖掉？ | 【实录】 | **跨两条消息追账**。机器只回当前这一句，不做"你刚才还说过什么"的对照 |
| 3 | 可爱是夸那只狗，还是夸本鱼？选一个，别含糊。 | 【实录】 | 逼对方二选一。客服永远给台阶，人偏不给 |
| 4 | 那MSI干脆改叫季前热身赛，奖杯上刻句"季中有效"得了。 | 【实录】群聊 | 归谬法：不反驳立场，**把立场推到荒唐**。机器倾向两边都有道理 |

| 7 | 认爹认到机器人头上，你也就这点出息 | 【产品】venomous | 反弹对方的**动作**（认爹），不另起一个新的骂词。这是"抓成分"的最硬形态 |

**为什么掺了 3 条自己系统的实测产出**：只拿外部语料当标尺，只证明"别人够得着"。

### 14.2 说方位，不说坐标

新增一节（和死规矩四是一件事的两面）：

| 要说 | 不要说 |

| 你左边 / 你后面 / 树后头 / 坡上 / 我这边 / 往那边走 | 坐标、方向轴、具体距离 |

### 14.3 多人：只给定性，不加规则

**没有**加"第几个说话的人优先""几分钟内不重复回应"这类规则——实测没数据前加规则，
只会把它变回客服。这条等真实多人日志再说。

### 14.4 意外收获：抓到一次"思考过程漏到公屏"

### 15.1 危险态硬截断（`say()`）

### 15.2 思考泄漏：从"枚举词"升级成"结构判据"

| 类别 | 例子 |

**一句话里命中 ≥2 类 = 思考泄漏 → 整句不发。**

### 16.2 元语言判据（加了第六类，单独命中就拦）

`metaSignals()` 原来五类，现在加第六类 **元语言**：
`带名字 / 带上名字 / 点名 / 要不要说 / 该不该说 / 还是不说 / 得再补一句 / 换个说法 / 措辞`

并且：**这一类单独命中就拦**，不等 ≥2 类——
因为"带名字""换个说法"这种话，人在游戏里不会对别人说，只会对自己说。

验收：`喊一句 P20 等等，带名字，2` → 拦；`你叫什么名字`、`我喊你名字了没` → 放行。

### 16.3 血量一致性（代码层）

`_replyInner` 现在把 `dangerOf(stateLine).hp` 存进 `this._hp`，`say()` 里对账：

> 实际血 <18 却说「满血 / 血是满的 / 血没掉」→ 整句不发

验收：`_hp=14` 说"我血是满的"→ 拦；说"血不多了 快跑"→ 放行；`_hp=20` 说满血→ 放行。

### 16.4 刷屏的真因不是 `danger`，是**每个实例各算各的**

Lead 说"`danger` 为真就走快速通道"——查了代码，**不成立**：
`const minGap = opts.allowFast ? this.fastSayGapMs : this.sayGapMs`，

  211 条 [say]，任意 20 秒窗口最多 37 条，最短间隔 0 秒
