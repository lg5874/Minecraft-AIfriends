# 小徐 · 长期记忆方案调研

> 调研了 MemoryOS（EMNLP 2025）、mem0（68.8k★）、HippoRAG、ai-npc-agent、Voyager 的记忆实现。
> 结论是：**不能照抄任何一个**。原因在下面第一节。

---

## 一、先说我现在的实现错在哪

我现在写的是：**人、事、地点、事实、教训，五个平铺的列表，只增不删。**

这有三个致命问题：

1. **他能记住一切，反而不像人。** 真人记不住"张三 3 天前给我 2 个铁锭"这种细节，但会记得"张三这人挺够意思"。全记住 = 数据库，不是人。
2. **上下文会爆。** 现在 `digest()` 只取最近 N 条，等于**旧记忆被静默丢弃**——不是"忘了"，是"根本没机会想起来"。
3. **没有权重。** 被王五打一次，和一起挖了两小时矿，在我这里是同样一条 event。真人完全不是这么存的。

## 二、调研到的三个关键机制

### 2.1 MemoryOS 的三层 + 热度（EMNLP 2025，最值得抄）

```
短期  这一轮对话，按页切（page）
  ↓ 溢出时
中期  一次上线的完整经历，按"段(segment)"存
      每段算一个热度： heat = α·访问次数 + β·交互长度 + γ·时间衰减
      容量满了就淘汰热度最低的（LFU/LRU）
  ↓ 被淘汰时
长期  从淘汰的段里提炼：用户画像 + 知识
```

**核心是"热度"这个概念**：常被想起来的记忆会浮上来，长期不用的会沉下去。
公式 `R_recency = exp(-Δ小时 / τ)` —— 时间越久，权重按指数衰减。

> 这正是"人味"的来源：**不是全记住，是按重要程度记。**

### 2.2 mem0 的四操作（68.8k★，全世界最流行的记忆层）

它不存原文，而是**先提取成一条条"事实"，再跟已有记忆比对，决定四个动作之一**：

| 动作 | 什么时候 |
|---|---|
| `ADD` | 全新的信息 |
| `UPDATE` | 跟已有记忆冲突，用新的覆盖旧的 |
| `DELETE` | 新信息推翻了旧的 |
| `NONE` | 已经有了，不重复存 |

这解决了我的一个大问题：**同一件事被反复说，不会存成十条。**

### 2.3 ai-npc-agent 的"记忆代谢"（中文项目，最贴近我们要的）

每条记忆带四个字段：**来源 / 跳数 / 保真度 / 确信度**。

- **转述会失真**：A 告诉 B 的事，B 再告诉小徐，保真度下降
- **但确信度反而上升**：人传话就是这样，"我听说……"越传越肯定
- **长期不用的降级**成"记不清了"
- **秘密不进传闻**

这条特别值钱：它让记忆**会变形**，而不是精确存档。

## 三、我打算怎么改（针对小徐，不是通用方案）

### 3.1 数据量根本不需要向量库

我们一共 3~4 个玩家。全部记忆加起来几千条顶天了。
上 embedding 模型 + 向量库是过度设计，而且要额外跑一个模型。

**用"关键词 + 时间衰减 + 情感强度"打分检索就够了。**

### 3.2 每条记忆带权重

```js
{
  text: "王五又打我了",
  who: "王五",
  kind: "grievance",
  emotion: 0.8,        // 情感强度 0~1，被感动/被激怒的高
  importance: 0.7,     // 重要性，模型判断
  tellCount: 0,        // 被转述过几次（越高越失真）
  certainty: 0.9,      // 确信度
  created: 时间戳,
  lastRecall: 时间戳,  // 上次被想起来是什么时候
  recallCount: 0       // 被想起来过几次（= 访问频率）
}
```

检索打分：
```
score = 相关性(关键词) × 0.5
      + 情感强度 × 0.2
      + 重要性 × 0.2
      + 新鲜度 exp(-天数/30) × 0.1
      + 被回想次数加成（每次 +0.05，上限 +0.3）
```

### 3.3 三层，但按"游戏"重新定义

| 层 | 内容 | 生命周期 |
|---|---|---|
| **眼前** | 这一段正在干什么、刚才谁说了什么 | 这一轮任务 |
| **这次上线** | 从上线到下线发生的所有事，走的时候压缩成一段"今天干了啥" | 每次上线 |
| **长期** | 人（谁是谁、恩怨、给过什么）、地方（家、矿洞、村）、事（答应过什么）、本事（会什么） | 永久，但会衰减 |

### 3.4 会忘，才是人

- 一条记忆超过 30 天没被想起，**强度减半**
- 超过 90 天，**降级成模糊版本**（"好像跟谁挖过矿，记不清是谁了"）
- 只有 `emotion > 0.7` 或 `importance > 0.8` 的，**不衰减**（刻骨铭心的事）

**这不是 bug，是核心功能。**

### 3.5 写入要挑，不是每句都记

不是每句话都进记忆库。用一个便宜的判断：
> 这句话里有新信息吗？有情绪吗？跟人有关吗？

三个都是"否"就丢掉。这样记忆库才不会变成聊天日志。

## 四、我需要你定的几件事

1. **他该不该忘？** 这是最核心的一条。我倾向"会忘"（像人），但你可能想要"全都记得"。
2. **记不记得细节？** "张三给过我 3 个铁锭" vs "张三给过我铁"。
3. **他下线的时间算不算数？** 真人下线后时间照走。他隔三天上线，该记得多少？
4. **会不会记错？** 真人会记混。要不要让他偶尔记错人/记错事（更像人，但可能让你抓狂）。
5. **记忆存哪？** 现在存在服务器 `plugins/XJJBot/bot/data/runtime/memory.json`。要不要能导出、换服务器能带走？
