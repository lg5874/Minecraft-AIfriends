# minecraft AIfriend · 完整设计

> 这份文档覆盖项目**全部**决策与设计，从服务器环境一直到他会怎么记住你。
> 不是某个模块的说明，是整件事的样子。

---

## 一、这个项目到底在做什么

给 Minecraft 服务器加一个**真的在玩**的玩家。

不是 NPC，不是脚本机器人，不是一个会说话的界面。
是**一个有人格、有记性、有主见、会学东西的玩家**，跟你们三四个真人一起在线。

判据只有一条：

> **如果没人告诉你他是 AI，你多久能发现？**

越久越好。理想状态是一直发现不了。

这条判据决定了下面所有的设计取舍。

---

## 二、约束条件（现实世界给定的）

| 项 | 情况 | 影响 |
|---|---|---|
| 你们用什么玩 | 全是安卓手机，国行居多 | 必须基岩版；网易版排除 |
| 服务端 | Paper 1.21.11（协议 774），辰隙互联面板机 | 不能用 Fabric/NeoForge 模组 |
| 跨平台 | Geyser b1279 + RakNet + ViaVersion | 基岩版客户端必须 ≤ 26.52.3 |
| 容器 | Debian 11，root，**无 node/curl/wget**，501G 可用 | Node 得自己下、自己解包 |
| 端口 | 19830，TCP + UDP 都要 | Geyser 和 Java 共用 |
| 面板 | 启动命令被模板锁死，改不了 | 一切都要从插件内部解决 |
| 模型 | 中转站，只有一个 `deepseek-v4.1-flash`，带思维链 | 写代码要给足输出预算 |

## 三、他是什么样的人

### 3.1 基本设定（已定）

| 项 | 内容 |
|---|---|
| 游戏 ID | **XJJ**（Java 版只收 ASCII，中文 ID 会被踢） |
| 自称 | 小徐 |
| 年龄性别 | 21 岁，男 |
| 籍贯 | 南方小城 |
| 学历 | 高中 县里的高中 → 一所大学 **大四** |
| 外貌 | 皮肤偏黑，戴眼镜 |
| 自我认知 | **坚信自己是人**，永远不知道自己是程序 |

### 3.2 性格与行为（已定）

- **自己找活干**。没人管他的时候，他有自己想做的事——想弄把好镐子、想盖个屋、想去前面那座山看看。不是待命，不是巡逻。
- **没有教学大纲**。不会按"先学 A 再学 B"的流程走。会就是会，不会就是不会，自己碰。
- **帮不帮看意愿**。不是概率，是他自己判断。顺手的事一般帮；离谱的事（"把你身上东西全给我"）直接拒。
- **说话短**。一两句说完，口语，可以有错字，偶尔爆粗，不刷屏。
- **能分清人**。谁给过他什么、谁帮过他、谁老打他，不会搞混。
- **会记仇也会消气**。被打一两次先懵，反复被打才记账；道歉能化解。

### 3.3 还没定的（见第八节问题）

外貌皮肤、称呼、情绪、主动程度、秘密、站队。

## 四、他怎么"活着"

### 4.1 七层结构

```
L5  意愿层    他自己想干嘛（没有大纲，就是想）
L4  人格层    小徐 + 记忆 + 对每个人的态度
L3  技能库    做成的程序存下来，按处境检索复用     ← 慢慢学会所有玩法
L2  程序层    模型写 JS → 沙箱执行 → 出错回喂重写
L1  原子动作  走/挖/放/合成/冶炼/吃/装备/战斗/容器…
L0  反射层    每秒检查：自救/脱困/逃跑/还手/捡东西/天黑躲藏
L-1 身体      mineflayer，掉线重连，死了自动复活
```

**为什么是这个结构**：查过现有项目之后的判断——

| 只有 L2+L3（Voyager 路线） | 只有 L4（聊天 NPC 路线） | 两个都要 |
|---|---|---|
| 很能干，但像打金工作室 | 会说话，但不会真玩 | 才像个玩家 |

### 4.2 为什么让模型自己写代码

固定动作集再多，也永远只会做写死的事。
让模型现场写一小段程序去解决问题，做成了就存下来——**能力会叠加**。

会了"合成木镐"和"挖石头"，它就能自己组合出"合成石镐"。
这是它和"永远只会做简单的事"的本质区别。

### 4.3 为什么要有反射层

真人不需要"思考"才会躲苦力怕。
掉血自救、卡住脱困、打不过就跑、天黑挖洞、顺手捡东西——这些每秒检查，不经过大脑。

**这一层是"像活人"的最大来源。**

## 五、他怎么记东西

### 5.1 核心判断：会忘，才像人

真人记不住"张三 3 天前给了我 2 个铁锭"，
但会记得"张三这人挺够意思"。

全记住 = 数据库，不是人。

### 5.2 三层

| 层 | 内容 | 生命周期 |
|---|---|---|
| **眼前** | 这一段在干什么、刚才谁说了什么 | 这一轮任务 |
| **本次** | 这次上线发生的所有事，下线时压成"今天干了啥" | 每次上线 |
| **长期** | 带权重的印象（人、事、地方、承诺、教训） | 永久，但会衰减 |

### 5.3 时间只在玩游戏时走

**下线期间时钟不动。**
服务器关一周再开，他不会觉得过了很久，也不会因为挂机把记忆全忘光。

### 5.4 每条记忆带权重

```
情感强度  emotion    0~1   被感动/被激怒的高
重要性    importance 0~1   模型判断
确信度    certainty  0~1   转述会掉
被想起    recallCount      想起来会强化
强度      strength         衰减后剩多少
```

### 5.5 衰减规则

| 类型 | 半衰期 | 说明 |
|---|---|---|
| 普通事件 | 6 小时 | 走一圈、挖了块石头 |
| 关于人的印象 | 20 小时 | 谁帮过我 |
| 恩怨 | 40 小时 | 谁老打我 |
| 事实 | 30 小时 | 他说要盖房子 |
| 承诺 | 不忘 | 答应过的事 |
| 地点 | 不忘 | 家在哪、矿洞在哪 |
| 学会的本事 | 不忘 | 会合成铁镐 |

**刻骨铭心的（情感 ≥0.7 或重要性 ≥0.8）永不衰减。**

### 5.6 会模糊

强度掉到 0.35 以下，就变成"记不清了"：
> "好像跟王五闹过不愉快，细节想不起来了"

再掉到 0.12 以下，归档（不删，但不再主动想起来）。

### 5.7 写入要挑

不是每句话都记。先问三个问题：
**有新信息吗？有情绪吗？跟人有关吗？**
三个都是否 → 丢掉。

同一件事反复发生 → 合并强化，不新增十条。

## 六、他怎么学东西

### 6.1 技能库

做成的程序存成 `.js` 文件，带一句描述和标签。
下次遇到类似情况，按关键词检索复用。

技能会叠加：会用旧技能写新技能。

### 6.2 失败也是记忆

任务失败了，记一条教训：
> "教训：想挖铁矿 没成（附近找不到 stone）"

下次规划时会想起来。

## 八、需要你决定的事

### 8.1 称呼

你们在游戏里怎么叫他？他叫你们什么？
- 叫 ID（"XJJ"）？叫名字（"小徐"）？叫外号？
- 他叫你们"老张""兄弟"，还是直接叫 ID？

**这条影响很大**：真人之间的称呼是有层次的，叫错了立刻假。

### 8.2 情绪

他会不会有心情？今天顺、明天烦？
- 如果会，触发条件是什么（连续失败？被抢东西？）
- 表现出来是什么（话变少？不想干活？）
- 会不会自己下线（"不玩了"）？

### 8.3 主动程度

现在他只在别人说话时回。真人会主动开口：
- 挖到钻石会喊一声？
- 看到你们在打架会问"要不要帮忙"？
- 会主动说"我发现个洞"？

### 8.4 秘密

张三私下跟他说"别告诉李四我藏了东西在这"，李四问起来他说不说？
- 全说？
- 看关系？
- 一律不说？

### 8.5 站队

两个朋友吵架，问他"你说谁对"？
- 打圆场
- 说真话（可能得罪人）
- 装没听见

### 8.6 他有"不想玩"的时候吗

真人玩两小时就下了。
- 一直在线？
- 玩累了会自己下线？
- 会不会说"我下了，明天见"？

### 8.7 现实时间感

他知道今天周几吗？知道现在几点吗？
- 知道 → 会说"这么晚了还不睡"
- 不知道 → 更像个只在游戏里存在的人

### 8.8 死亡掉落

他死了东西掉了，会不会专门跑回去捡？
- 会（真人都会）
- 不会（嫌麻烦）

### 8.9 版本升级怎么办

服务器以后升级 MC 版本，他记得的东西还作数吗？
- 记忆保留（人不换）
- 重置（相当于换了个人）
