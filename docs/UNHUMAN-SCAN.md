## 0. 一句话总览

**最露馅的不是他"做错事"，是他"从不停、从不看人、从不累"。**

一个 25 分钟的会话里：54 次玩家上下线他一次没搭理，说了 8 句话其中 5 句是纯标点，482 次"走不通了"平均 2 秒一次，同一格坐标站了 4.5 分钟，长期目标平均活 8 秒。玩家看到的不是一个笨人，是一个**卡在循环里的东西**。

## 一、说话层面（4 条）

### 1. 公屏上只有句号：`[say] 。` 出现 4 次、`[say] 。。` 1 次

**证据**（`data/runtime/bot.log`，全文只有 8 次 `[say]`）：

```
[16:17:03] [say] 。
[16:19:39] [say] 。
[16:23:32] [say] 。
[16:27:41] [say] 。
[16:27:46] [say] 。。
```

**代码位置**：
- `src/talk.js:184-186`：`if (!out || out.includes('[不说]')) return false` → `out = cleanLine(...)` → `if (!out) return false`
- `src/talk.js:692-701` `cleanLine`：只剥引号、去前缀、截断，**不检查是否只剩标点**
- `src/talk.js:87-93` `say()`：只过 `isLeak` 和 `isMachineTalk`，两个都不拦标点

我实测复刻 `cleanLine`：

```
"。"        -> "。"      ← 原样通过
"。。"      -> "。。"    ← 原样通过
"...":      -> "..."     ← 原样通过
"。\n（不想说）" -> "。"   ← 模型可能输出了"不想说"的变体，被截成句号
```

**为什么不像人**：真人在公屏上发一个句号，是打字打到一半、或者手滑、或者装神秘——**偶尔一次**。25 分钟发 4 次纯句号，而且都在自言自语场景下，只会让人觉得"这号在测试/挂机/坏了"。这比不说话还糟。

**严重度**：**一眼看出**。这是公屏，所有人都看得见。

**修法**：
1. `cleanLine` 结尾加 `if (!/[\u4e00-\u9fa5a-zA-Z0-9]/.test(t)) return ''` —— 一个汉字/字母/数字都没有就当没说话。
2. `say()` 里再加一道：`if (t.replace(/[^\u4e00-\u9fa5a-zA-Z0-9]/g,'').length < 1) return false`。
3. 如果模型反复输出标点，说明 `speak` 的提示词让它在"不想说"时没干净地输出 `[不说]`——检查 `src/talk.js:161` 那句提示是否够醒目。

### 2. 同一句话 98 秒内说了两遍

**证据**：

```
[16:42:29] [say] 东西带齐了，下去转转
[16:44:07] [say] 东西带齐了，下去转转     ← 一字不差
```

**为什么不像人**：这正好踩中用户早就抱怨过的"同一件事回了两遍，很人机"。之前修的是**回复路径查重**（`repliedMsgIds`），但这条是**主动说话路径**，两句话的 situation 不同（一次是"带上吃的和火把再出门"完成，一次是同一个技能又跑了一遍），所以查重不生效。

**代码位置**：
- `src/talk.js:45-69` `fatigueHint()`：确实检测到了"相邻两句开头两字相同"，会往提示词里塞一段"你最近说过 X，必须换"。
- **但它只是提示词**。模型可以无视，而且这次就无视了。
- `src/spontaneous.js:101` `cooldownMs = 90000`（90 秒）——两句话隔 98 秒，正好过了冷却。

**严重度**：**玩久了才觉得**。玩家得在同一片区域待够两分钟才听到。

**修法**：`fatigueHint` 之外加一道**硬拦截**——在 `say()` 里比对 `recentSaid`，如果和最近 3 句里任何一句**完全相同**（或去掉标点后相同），直接 `return false`。宁可这次不说话，也不能复读。

### 3. 54 次玩家上下线，他一次招呼都没打

**证据**：

```
玩家上下线事件：54 次（grep -c "上线了\|下线了"）
他说的话：8 次，全部是自言自语
包含人名的发言：0 次
```

具体例子——`[16:15:57] TMGepccj4 上线了`、`XJJ_E2E6o5d 上线了` 之后，他下一句话是 `[16:17:03] [say] 。`。

**为什么不像人**：真人玩 MC，有人进服第一反应是"哟""来了"或者至少瞟一眼。54 次里 0 次反应，等于**他看不见人**。

**代码位置**：
- `main.js:137-141`：`playerJoined` → `spont.push(spontaneous.onPlayerJoin(p.username))`
- `src/spontaneous.js:85-87`：`onPlayerJoin` 返回 `chance: 0.5`
- `src/spontaneous.js:109`：`if (this.pendingEvents.length > 6) this.pendingEvents.shift()` —— **队列上限只有 6，超了就丢最老的**
- `src/spontaneous.js:122`：非吐槽类受 90 秒冷却限制

**算一下**：54 次事件挤进一个上限 6 的队列，前面 48 条直接被丢掉。剩下的还要过 0.5 概率 + 90 秒冷却。理论上最多说 16 次，实际说 0 次。

**严重度**：**一眼看出**。玩家进来打招呼没人理，第二次就不打招呼了。

**修法**：
1. `onPlayerJoin` 的 chance 提到 0.85，并且**不受 90 秒冷却限制**（有人来是即时事件，不是"攒着想说的话"）。
2. 队列别丢 join/leave——它们比"附近有 stone 被挖掉了"重要得多。可以给事件加优先级，或者干脆 join/leave 走单独一条立即路径。
3. 别让它变成"每个人来都喊一句"——用 `mem.people[username]` 判断是不是熟人，熟人喊名字，生人瞟一眼（"有人来了"）。


**为什么不像人**：他刚说完"下去转转"，2 秒后原地改主意，7 秒后失败，然后 10 秒后又说了一遍"东西带齐了，下去转转"。**声明和行动完全脱钩**。真人说完"我下去了"至少会真的往下走一段。

```js
return '现在手上有圆石' + actions.countOf('cobblestone') + '个，石料总共约' + finalCobble + '个，够垫脚用了'
```

**无条件 return 成功文案**，无论有没有真的捡到东西。而 `judgeOutcome` 的 `hasGain` 正则（`main.js:1304-1310`）里有 `/[1-9]\d*\s*(块|个|根|把|颗|件)/`，"圆石132个"正好命中 → 判成功。

3. `skills.markUse(name, true)` 的前提应该是"背包真的变了"，不是"代码没抛异常"。

### 10. 心情永远 irritated，energy=0 却从不喊累

**证据**：

```
全部 60 次心跳，心情分布: 36/36 都是 irritated（有心情字段的那 36 次）
data/runtime/mood.json: {"energy":0, "spirit":0.9986, "irritation":0.805, "satisfaction":0.998}
```

**代码位置**：`src/mood.js:115-122` `state()` 的判定顺序：

```js
const bad = this.irritation
if (bad > 0.6) return 'irritated'      // ← 先判这个
if (this.energy < 0.25) return 'tired' // ← 永远走不到
```

`irritation` 一旦过了 0.6，**energy 检查就永远轮不到**。他的 energy 已经是 0（掉到 0 需要 4.2 小时纯在线，确实掉了），但 `state()` 永远返回 `irritated`，所以 `describe()` 永远输出"你现在很烦，谁跟你说话都想呛回去"。

而 `src/mood.js:65` 的 `tick()` 每分钟只减 0.006 烦躁——从 0.8 降到 0.6 需要 **33 分钟**。测试会话只有 25 分钟，所以他整局都是同一张脸。

**为什么不像人**：真人不会连续 25 分钟保持同一个情绪。而且 energy=0 的人不可能还在精神抖擞地挖矿——**他的身体状态和实际行为完全脱节**。

**严重度**：**玩久了才觉得**（说话会一直带刺，玩家会觉得"这人怎么一直不高兴"）。

**修法**：
1. `state()` 改成**取最严重的那个**，不是取第一个命中的。比如 `energy < 0.15` 时优先返回 `tired`。
2. `energy` 掉到 0.2 以下应该有**行为后果**：主动停下来、说"不行了我得歇会儿"、找个地方坐着。现在 energy 只影响 `impulse.maybe()` 的概率 +0.1（`src/impulse.js:131`），等于没有。
3. `irritation` 的衰减速率按"有没有人惹他"区分——没人惹他的时候应该掉得快。

### 12. 游戏内时间感也是断的：25 分钟里"天亮了"两次

**证据**：

```
[16:17:44]   · 天快亮了
[16:19:15]   · 天亮了，白天
[16:37:50]   · 天快亮了
```

MC 一个昼夜是 20 分钟，25 分钟里天亮两次是正常的。但问题是：**他没有任何"白天/黑夜"的行为差异**。`main.js` 的躲夜逻辑要求 `tod > 13000 && tod < 23000 && bot.health <= 14`（`main.js:592` 附近），而他的血全程 20/20 —— 所以**永远不会触发躲夜**。

**为什么不像人**：真人天黑会紧张、会想回家、会插火把。他完全无感，因为触发条件是"血少"而不是"天黑了"。

**严重度**：**玩久了才觉得**。

**修法**：躲夜的条件不该绑血量。天黑本身就该有反应——至少"想回屋"或者"点个火把"，即使血是满的。

## 四、社交层面（2 条）

### 13. 记忆里 5 个"认识的人"全是他自己的测试小号

**证据**（`data/runtime/memory.json`）：

```

第一次见到 XJJINTG         importance 0.6
第一次见到 XJJHOME87       importance 0.6

```

`XJJHOME6 / XJJINTG / XJJHOME87 / XJJVER6` 全是测试号（名字带 XJJ + 用途后缀）。

**为什么不像人**：他的"人际关系"记忆里 80% 是测试脚本。如果哪天玩家问"你还记得谁"，他会报出一串不存在的名字。而且这些条目 `importance: 0.6`，衰减很慢，会长期占着 `peopleDigest` 的位置。

**代码位置**：`src/talk.js:260-267`，`isNew` 就写一条 `第一次见到 ${username}`，**不过滤名字**。

**严重度**：**细微**（玩家不会直接看到），但会污染"他认识谁"这条拟人化线。

**修法**：`mem.add` 时过滤掉测试号（复用 `looksLikeBot` 那套正则），或者干脆清一遍 `data/runtime/memory.json` 再开新档。

### 14. 他从不主动找人，也从不回应"有人来了"

和第 3 条是一体两面：**主动说话的触发源里，没有"人"这一类**。

**证据**：8 次 `[say]` 的触发源统计：

| 触发源 | 次数 | 内容 |
|---|---|---|
| 任务完成/失败 | 5 | `。` `。` `。` `。` `。。` |
| 技能重复完成 | 1 | `看不懂啊` |
| 技能重复完成 | 2 | `东西带齐了，下去转转`（重复） |
| 玩家上下线 | **0** | — |
| 玩家说话 | **0** | （这一局没有玩家聊天） |
| 主动搭话 | **0** | — |

`src/spontaneous.js` 里其实有 `onFriendInDanger` / `onFriendBusy` / `onPlayerJoin` / `onPlayerLeave` 四个社交事件，但：
- `onFriendInDanger` 需要 `perceive` 检测到"别人血少"——这一局没触发。
- `onPlayerJoin/Leave` 被队列上限和冷却吃掉了（第 3 条）。

**为什么不像人**：真人在多人服里是**有社交驱动的**——看到熟人上线会喊，看到别人被怪围会过去帮。他完全没有。

**严重度**：**玩久了才觉得**。

**修法**：给 `onFriendInDanger` 加一条真实的触发链（`perceive.describeThreats` 已经在算附近实体了，可以顺便算别人的血）。这是最能体现"像人"的行为——**看到别人挨打过去帮忙**，比说一百句"我烦"都有效。

**触发条件**：`looksLikeBot(username)` 为 true，即名字匹配 `/^(bot|ai|npc|_bot|bot_|XJJ\d+|Test\d*)/i` 或在 `cfg.behavior.botNames` 里（当前是 `XJJ1..XJJ5`）。

### 16. `idleThinkSeconds: 60` 配置项从未被使用

**证据**：

```
$ grep -rn "idleThinkSeconds" src/ main.js
（无输出）

config.json: "idleThinkSeconds": 60
```

主循环固定 `await sleep(4000)`（`main.js:585`、`789`、`1647`），**4 秒一轮**。

**为什么这会让玩家觉得不像人**：任务之间的间隔实测中位数只有 10 秒，10 次 ≤5 秒，4 次 ≤2 秒。真人做完一件事会愣一会儿、会想、会走两步。他 1 秒内就开始下一个任务（实测最短间隔 1 秒）。

**严重度**：**玩久了才觉得**（节奏感）。

**修法**：要么删掉这个配置项（假装没有），要么真的用起来——**任务之间插一段 5–30 秒的随机发呆**，期间可以站着看、转身、跳一下。这是最便宜也最有效的拟人化。

## 七、一句话结论

**他最不像人的地方，是"从不看人、从不停下、从不累"——而不是"做错事"。**
