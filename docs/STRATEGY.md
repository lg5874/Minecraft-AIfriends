## 2. 假进展有三层，UNHUMAN-SCAN 只写了第一层

### 层 1（已写，第 8 条）：判定看话术
`main.js:1149` `if (result.ok && verdict.ok)`。
`result.ok` = 代码没抛异常；`verdict` = `judgeOutcome(文本)`，读的是模型自己写的结尾话术。
→ 「铁锭0」被判「完成」。

### 层 2（**没写，是放大器**）：成功信号回灌技能库
`src/coder.js:106` `this.skills.markUse(sk.name, out.ok, ...)`
`out.ok` 同样是"JS 没抛异常"。
→ 这条技能成功率 88% → 复用排序把它排到最前面 → 下次还用它 → 还失败 → 还记成功。

**这是正反馈。skills-owner 报的「复用率 0%→95%」不是胜利，是把一次假成功固化成了他的全部行为习惯。**
现在的实际情况：**他越"熟练"，越死。** 39 条技能里最高分的那个，是那条产不出铁锭的。

### 层 3（**没写，目标层也在白送**）：`goals.js:965`
```js
if (s.kind === 'do' || s.kind === 'build') this.addWork(progress || 1)
```
`progress` 是 undefined → 硬 +1。而这类阶段 `need: {count: 1}`。
**→ 任何一个 kind='do' 的阶段，一次任务报"完成"，阶段就完成。无条件。**
`goals.json` 里「一层层往上码，搭到高处」就是这么 97 秒"完成"的（work=1, ratio=1, attempts=1）。

还有 `need: {'#surfacestone': 40}` 是**存量**不是增量：他开局就有 130 块圆石 → `ratio: 1` → 零动作完成第一步。

**结论：UNHUMAN-SCAN #9「目标活 8 秒」加"最低存活时间"是治标的。根是阶段自己会白送完成，所以目标推进得快、换得也快。**

## 5. UNHUMAN-SCAN 完全没覆盖的两条（我认为比 16 条里的 12 条都重要）

### 盲点 A：他没有"有人在看"这一维

`src/spontaneous.js:622 scanPeople()` 已经能认出 8 格内的人，但它**只用来决定"说不说话"**（`onPlayerNearby` / `onPlayerLinger`），从来不影响**做什么**。

真人被盯着挖矿会紧张、会挖歪、会显摆、会说"看啥呢"、会故意多挖两下。
他动作 100% 稳定，因为他的行为和有没有人看完全无关。

**这条在多人服里比句号还容易暴露——玩家不用读日志，站旁边看 30 秒就知道了。**
而那正是用户唯一的观察方式。

### 盲点 B：他没有"不擅长的事"

他做 8 件事的成功率都在 60-70% 同一档。真人是有**技能画像**的：有人会建房不会红石，有人会挖矿不会种地。
一个"什么都会一点、什么都不精、而且均匀地不精"的玩家，本身就是 bot 的指纹。

# 第二轮：回答 Lead 的三个问题

## 1. 恐怖谷怎么破 —— 第三条路：引入「代价」

**16 条要修，但修完只是回到 0。** 我不是说要少修，是说**修完不会自动变像人**。

看代码（这是新证据，不是推测）：

- `main.js:503 onDeath()` → `mem.add({text:'死了：'+how, importance:0.5})` → 然后**没有任何地方读这条记忆来改变以后的行为**。
- 全项目对 memory 的"读"只有三处：`mem.lastSummary()`（提示词里一句"上次下线前在"）、`mem.hitStats()`（老打我的人 → 记仇，这条是真的）、`mem.remember(pos)`（地点）。**"我白干了一小时"这一类，一处都没有。**
- 服务器还是「死亡不掉落」，所以死亡连物质代价都没有。

**结论：他没有代价。**

人格 = 你愿意为什么付多少。一个不付出、不损失、不心疼的东西，不会像人——**因为真人正是靠"犯错+付代价"被认出来的**。修完 16 条，他变成"不会出错的 NPC"，那比现在更难被发现，但一旦被发现更确信。

### 具体第三条路（不需要新模块）

**a. 结算。** 每次放弃长期目标时，算一笔账：这一轮花了多久、拿到多少、差在哪。现在 `goals.abandon()` 直接换路，**从不结算**。日志里 49 次重复、累计约 37 分钟，他没有一次说"我这一小时全白干了"。

**b. 记忆要有牙。** 死亡/白跑要能影响下一次选择：刚在深层被岩浆烫死 → 一段时间内不选深层目标；刚白干一小时 → 不再接同类任务。

**c. 时间要值钱。** 他不会说"这一小时亏了"，因为他没有"这一小时"这个概念。

### 顺带一个更硬的结论

**用户的"吐槽没活人感"，根因不是词汇，是素材。**
真人吐槽是**过去式的、有账的**（"我他妈挖了一晚上全是石头"）。他只能吐槽"这一秒发生了什么"（"走不通了"）。**没有损失就没有可吐槽的东西。**

→ 所以 `tone-researcher` 调 2026 网语是白费：**它要调的素材不存在。** 不是顺序问题，是没有对象。
