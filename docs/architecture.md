> 目标：不是一个会挖矿的脚本，而是一个**能自己摸索、慢慢学会全部玩法、并且坚信自己是人**的玩家。

### 伤势与恩怨（不是概率，是判断）

不写"30% 概率还手"这种。写的是**记忆 + 情境**，让他自己判断：

- 每次被打，记一条：`谁、什么时候、几下、当时在干什么、周围有没有别人`
- **第一次、第二次**：他"没反应过来"，可能只是走开、或者问一句"你干嘛"
- **同一个人反复打**：这条记忆权重上升，形成"这人老打我"的印象
  → 之后见了他会绕开、会防备、被打了会还手
- **但不会永久记仇**：对方道歉、或者一起干过别的事（给过东西、帮过忙），这条印象会被冲淡
- **判断交给模型**：把"这个人打过我 5 次，上次是 20 分钟前，他没道歉"和"这个人昨天给了我一把铁镐"一起喂进去，让他自己决定这次理不理

| | bigph00t/hermescraft | 77 | 每个角色独立 SOUL/记忆/session，多智能体共享一个服务器 | ✅ 提示词与记忆分层可借 |

### 关键判断

- **只有路线①能实现"学任何东西"**。固定动作集（GITM）再强，也永远只会做写死的那些事。
- **只有路线③能让它像个人**。光会写代码的 agent，说话像个工具人。
- **两者必须叠在一起**，这就是没人做好的地方。
- **没有任何现成的 Paper 服务端 AI 玩家**。搜遍 GitHub，Paper/Spigot 侧全是"聊天 NPC""建房子的 NPC"，没有"真的在玩"的。这块我们自己在做的东西是空白。

## 二、从源码里挖出来的具体机制

### 2.1 技能库（Voyager / mindcraft）

Voyager 的技能不是函数名清单，而是**真的存 .js 文件**：

```
skill_library/trial1/skill/code/
  craftWoodenPickaxe.js
  mineFiveIronOres.js
  smeltFiveRawIron.js
  craftIronPickaxe.js        ← 这个技能内部调用了前面几个
  ...
```

每个技能三件套：
1. **代码**（可执行 JS）
2. **一句描述**（再由 LLM 生成，不含函数名）
3. **向量**（用于按当前处境检索该用哪个）

学新技能时：把**当前已会的技能描述列表**塞进提示词，模型能组合已有技能写新技能。
→ 这就是"一步步摸索、慢慢熟知所有玩法"的机制来源：**技能会叠加**。

mindcraft 另加了一条比 Voyager 更实用的东西：**写完先 ESLint 校验，再在锁死的沙箱里执行；抛错就把错误信息原样喂回去让它重写，最多 5 次**。

### 2.2 自动课程（Voyager 的 curriculum）

每轮把"当前状态 + 已完成任务 + 失败过的太难的task"喂给模型，让它只输出**一个**下一步任务：
`Mine [数量] [方块]` / `Craft [数量] [物品]` / `Kill [数量] [怪物]`。

规则里有一条特别值得抄：**不让自己重复做同一件事，要去找稀有资源、升级装备**。
还有一条：**不做需要"看图确认"的任务**（放火把、挖个坑），因为这种没法自动验证成败。

### 2.3 三层记忆（ai-npc-agent）

| 层 | 内容 | 生命周期 |
|---|---|---|
| 短期 | 当前这段对话 | 关了就没 |
| 长期事实 | 谁说过什么、答应过什么、地图上的地点 | 永久，会检索 |
| 反思教训 | 从失败里总结的"下次别这样" | 永久，规划时插入 |

还有两个细节很值钱：
- **记忆代谢**：每条记忆带来源、保真度、确信度；转述会失真但确信度反而升高（像人传话）；长期不用的降级成"记不清了"。
- **失败归因写成教训**，下次规划时自动插入补救动作。这就是"同一个错误不会反复犯"。

### 2.4 自主模式（mindcraft 的 modes）

这些不是 LLM 决定的，是**常驻反射**，每秒检查：
`self_preservation`（掉血/掉虚空就自救）、`unstuck`（卡住了自己脱困）、`cowardice`（打不过就跑）、`self_defense`（被打了还手）、`hunting`、`item_collecting`（顺手捡东西）、`torch_placing`（暗了插火把）、`idle_staring`（发呆时东张西望/看玩家）。

→ **这一层是"像个活人"的最大来源**：真人有下意识的反应，不需要"思考"。

## 三、我们服务器的现实约束

| 约束 | 结论 |
|---|---|
| 服务端是 **Paper 1.21.11** | 所有 Fabric 模组方案（Numen、mc_aiplayer）全部出局 |
| 走 Geyser 让手机基岩版进来 | 不影响机器人，它走 Java 协议直连 |
| 容器里没有 node/curl/wget，但**是 root，能起子进程** | 已验证：插件能下 Node、装依赖、跑起来、连进服务器 |
| `minecraft-data 3.119` **原生支持 1.21.11 / 协议 774** | 方块、物品、合成表、掉落表全是现成的，不用自己录 |
| 账号名只能 ASCII | 用 `XuJunJie`，游戏内自称徐俊杰 |
| LLM 是中转站的 `deepseek-v4.1-flash` | 带思维链，写代码时容易把 token 全花在"想"上，要留足 max_tokens |

## 四、我要搭的东西（五层）

```
L5  课程层    自己决定"下一个该学什么"，记录会了什么、栽在哪
L4  人格层    徐俊杰 + 三层记忆 + 反思 + 对每个人的关系
L3  技能库    成功的程序存盘、写描述、按处境检索复用   ← "慢慢学会所有玩法"
L2  程序层    LLM 写 JS，ESLint 校验，沙箱执行，报错回喂重写
L1  原子动作  ~70 个可靠动作：走/挖/放/合成/冶炼/吃/装备/攻击/看箱子/种地/钓鱼…
L0  反射层    每秒检查：自救/脱困/逃跑/还手/捡东西/插火把/发呆         ← "像个活人"
L-1 身体      mineflayer，常驻，掉线重连，死了自动复活
```

**和别人的区别**：L4+L3 同时存在。只有 L3 是 Voyager，像个打金工作室；只有 L4 是聊天 NPC，不会真玩。

### 成长路径长什么样

- **第 1 天**：砍树 → 木板 → 工作台 → 木镐 → 挖石头 → 石镐。学会 6~8 个技能。
- **第 3 天**：找到铁矿 → 熔炉 → 铁镐铁剑 → 简单小屋。技能库 20+。
- **第 1 周**：种田、养动物、箱子分类、下矿洞带火把、遇到苦力怕会跑。
- **第 2 周**：下界（需要建传送门）、附魔台、村民交易。
- **之后**：他自己会组合已有技能写新技能，比如"自动农场"= 已有的种植+收割+箱子。

这套东西的上限由模型决定，不由我写死的代码决定。这是它和"永远只会做简单的事"的本质区别。

## 五、代价与风险（先说清楚）

1. **token 花费**。空闲时每 60~120 秒一次决策；写代码时一次 2000~4000 token。
   粗算一天几百万 token。中转站什么价你比我清楚，跑之前先看一眼余额。
2. **代码执行失败率**。Voyager 那种成功率不是 100%，会有反复重写。表现就是"他站那儿发了会儿呆又去试"——其实也像人。
3. **思维链模型写代码容易被截断**。要给它足够的输出预算，实在不行换一个不带思考的模型专门写代码，聊天用现在这个。
4. **安全**。生成的代码在沙箱里跑，禁网、禁文件、禁 `/` 指令，只能调原子动作。
