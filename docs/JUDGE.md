# 单判定器（src/judge.js）

**一句话**：判成功只看世界，不看话术。文本只有否决权。

## 为什么要有它

之前 `main.verifyTaskEffect` 和 `coder.verifySkillEffect` 是两份各写各的判据。
38 个真实技能 × 3 种世界状态实测：同一份证据两边结论差 **42%**
（"真挖了 2 格、背包没涨"：coder 20/38 vs main 4/38）。
后果不是"某趟判错"，而是**同一次运行里技能记成功、任务记失败**。

现在两边都调 `judge.judgeTask()`，一致性 100%（`scripts/test-judge-consistency.js`）。

## 五个证据维度

| 维度 | 来源 | 什么时候是唯一的证据 |
|---|---|---|
| `inv` 背包净变化 / 目标物增量 | `snapshotInv()` 前后比 | 挖矿、采集、合成 |
| `blocks` 周围方块变化 | `worldSig()` 绝对坐标快照 | 盖墙、铺路、挖通道（东西当场用掉了） |
| `move` 位移 | 两个位置的距离 | 去、走、探、搬 |
| `held` 手持物品 | `bot.heldItem` | 换装备（背包一点没变） |
| `food` 饱食度 / 食物增减 | `bot.food` + 食物类物品 | 吃东西（食物变少是**正常**的） |

## 三条被实测打脸过的规则

1. **目标物不能取"第一个被文本包含的中文词"**
   `用石镐挖圆石` 会先命中"石镐"，于是要求 `stone_pickaxe +1`；
   38 个技能里 14 个这么错。现在收**全部**候选，"用 X / 拿 X"里的 X 排除。

2. **世界快照必须绝对坐标**
   相对偏移 key + 第二次用当前 pos 取样 = 人一动所有 key 都变：
   实测"动了 2 格没挖"报 482 格变化。现在 key 是 `x,y,z` 绝对值，
   比较时锚定**任务开始那片区域**。

3. **blockAt 只吃 Vec3**
   mineflayer 内部 `block.position = pos.floored()`，传普通对象会抛异常，
   被 catch 吞掉就成了"读不到"—— 三轮真机日志里世界证据整整一维是死的（`方块?`）。

## 制作类只能靠产物背书

`做/合成/造/弄 + 具体产物`（工具、锭、工作台…）→ 只认那样东西真的进了背包。
"挖了两格方块"不能给"做石镐"背书。

## 证据类型（没有默认分支）

每个目标阶段必须声明用哪类证据验收，`judgeTask()` 拿到别的什么都不干先看这个：

| evidence | 验什么 | 用在哪 |
|---|---|---|
| `world` | 背包增量 / 目标产物 / 环绕方块 / 位移 / 手持 | 挖、砍、做、合、盖、搬、回地面 |
| `duration` | 待够 N 秒 + 位移<5 格 + 血没掉 + 没饿 | 歇着、守着、等天亮（**不看"待着"这两个字**） |
| `state` | 调用方给的 `stateOk` 布尔 | 明确状态判据 |

**没声明就 `throw`**。这不是洁癖：同一个病犯过五次（judgeOutcome 读话术 →
markUse 记"没抛异常" → `[proof]` 的 stay 豁免 → 证据类型缺失时的默认分支），
每次都因为"判据覆盖不到某类目标"而有人顺手开一个文本后门。
把默认分支删掉，后门就炸在自己手里，而不是静默放过。

阶段声明在 `src/goals.js`：`POOL` 模板加载时盖章，模型自编阶段走 `normalizeStage()`。
配套 CI：`node scripts/check-judge-discipline.js` —— 扫"对 goal/输出做正则 → 直接返回成功"
的写法（正则可用来决定**要求什么证据**，不能用来**批准**）。当前 0 违规，自带 `--selftest`。

## 与其它模块的分工

- `main.judgeOutcome` 只剩**否决权**（说了失败词就是失败），不再有批准权
- `coder` 复用技能前后收集证据，结论同样来自 `judgeTask()`
- `goals.onTaskResult({progress})` 的 `progress` 就是这里算出来的真实增量
