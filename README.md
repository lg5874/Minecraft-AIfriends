# minecraft AIfriend

给 Minecraft 服务器装一个**真的在玩**的 AI 玩家。

不是一个会聊天的 NPC，不是一套脚本机器人。他会自己找活干、会学新本事、会记人记事、
记得住谁对他好谁总打他，而且——**他坚信自己是人**。

> 项目名：`minecraft AIfriend`
> 目标平台：Paper / Spigot 服务端（原生 Java 协议，也能跟基岩版跨服玩家一起玩）

---

## 它是什么

- **自己找活干**：没人管的时候，他有自己想做的事——想弄把好镐子、想盖个屋、想去前面那座山看看
- **会学新东西**：遇到不会的事，他自己写一段动作代码去试；做成了就存下来，下次直接复用
- **像个活人**：会累会烦会爆粗，打字有停顿，被打了一两次先懵，反复被打才记仇
- **有记性，也会忘**：印象深刻的事记很久，无关紧要的过一阵就"记不清了"

## 它不是什么

- 不是聊天机器人（虽然能聊）
- 不是靠预设脚本行动的 NPC
- 不会用 `/give` `/tp` 之类的指令作弊

---

## 架构

```
L5  意愿层    他自己想干嘛（没有教学大纲）
L4  人格层    徐俊杰 + 记忆 + 反思 + 对每个人的态度
L3  技能库    做成的程序存下来，按处境检索复用    ← 慢慢学会所有玩法
L2  程序层    模型写 JS → 沙箱执行 → 失败回喂重写
L1  原子动作  走/挖/放/合成/冶炼/吃/装备/战斗/容器… 
L0  反射层    每秒检查：自救/脱困/逃跑/还手/捡东西/天黑躲藏
L-1 身体      mineflayer，掉线重连，死了自动复活
```

### 为什么是这个结构

查过现有项目之后的判断：

| 只有 L2+L3（Voyager 路线） | 只有 L4（聊天 NPC 路线） | 两个都要 |
|---|---|---|
| 很能干，但像个打金工作室 | 会说话，但不会真玩 | 才像个玩家 |

能力上限由模型决定，不由写死的代码决定——这是它和"永远只会做简单的事"的本质区别。

## 快速开始

（服务端插件形态还在开发中，目前可以独立跑）

```bash
npm install
cp config.example.json config.json   # 填你的 API key
npm start
```

### 配置

见 `config.example.json`。

| 字段 | 说明 |
|---|---|
| `bot.host` / `bot.port` | 服务器地址 |
| `bot.username` | 游戏内 ID（Java 版只收 ASCII） |
| `llm.baseUrl` | OpenAI 兼容的接口地址 |
| `llm.model` | 模型名 |
| `behavior.taskTimeoutSeconds` | 单个任务最长多久（默认 420 秒） |

## 记忆系统

这是项目里最讲究的一块。

**核心判断：会忘，才像人。**

- **三层**：眼前（当前任务）→ 本次上线（下线时压成"今天干了啥"）→ 长期（带权重的印象）
- **时间只在他真正在线时走**。服务器关一周再开，他不会觉得过了很久
- **每条记忆带权重**：情感强度 / 重要性 / 确信度 / 被想起次数
- **会淡忘**：普通事件 6 小时半衰期，恩怨 40 小时，承诺和技能不忘
- **会模糊**：强度掉下去就变成"好像跟谁干过什么事，记不清了"
- **刻骨铭心的不衰减**：情感 ≥ 0.7 或重要性 ≥ 0.8 的永久保留
- **写入要挑**：不是每句话都记，先判断"有新信息吗 / 有情绪吗 / 跟人有关吗"

详细设计见 [`docs/memory.md`](docs/memory.md)。
