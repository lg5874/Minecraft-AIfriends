# Minecraft AIfriends（MA）

**给 Minecraft 服务器装一个真的在玩的 AI 玩家。**

不是一个会聊天的 NPC，不是一套脚本机器人。
他有自己的事要做、有自己的品味和脾气、会记人记事、记得住谁对他好谁总打他。
而且——**他坚信自己是人**。

```
[23:53:16] 死了：XJJ was slain by Zombie
[23:53:20] [say] 草，被僵尸挠死了        ← 他自己编的，不是预设台词
```

> 为什么叫 AIfriends（复数）：目标是**多个 AI 玩家**一起玩、互相说话，
> 像普通玩家一样在服务器里共存。目前是第一个（徐俊杰）。

## 现在能做什么（实测数据）

| 能力 | 实测 |
|---|---|
| **砍树** | 63-87 秒砍到 6 块原木 |
| **放箱子 / 存东西** | 2-3 秒 |
| **找食物** | 27-52 秒拿到肉 |
| **做工具** | 木镐/石镐 3-35 秒 |
| **从地下爬出来** | 48.7 秒从 y=18 爬到 y=64（真寻路） |
| **回家** | 离家 95 格，48.7 秒走回，误差 2.9 格 |
| **记人** | 记住称呼、恩怨、一起干过什么 |
| **长本事** | 技能库复用率 89.8%，最热的技能复用 53 次 |

端到端成功率：**25% → 67%**（8 个典型任务，白天/夜晚/地下/地表混合场景）

## 他怎么"像个人"

### 会吐槽，但不会一直吐槽

```
挖半天啥也没有  → 抱怨这地方，或者说白费劲
被怪弄死        → 骂一句，越短越好
合成失败        → 骂合成，或者说材料又不够
自己干成了      → 一句短的认可，别庆祝
```

**十句话里带情绪的不超过三句。** 剩下七句平铺直叙。

### 被骂有反应梯度，不是客服

```
第一次被骂  → 懵：「？」「我干啥了」
继续骂      → 火：「你有病？」「招你惹你了」
还骂        → 骂回去，短、狠、不解释
```

**禁止说教腔**：「有事说事」「骂来骂去没意思」这类话真人说不出来。

### 不问名字

第一次见人就用游戏 ID 喊，不会问「怎么称呼」。
只有对方主动说「叫我老王」才改口。

### 会忘事

- 普通事件：6 小时半衰期
- 恩怨：40 小时
- 承诺 / 技能：不忘
- 刻骨铭心的（情感 ≥0.7）：永不遗忘

**但"重复念叨"不会让他记住** —— 同一句话重复 8 次也不会变成"刻骨铭心"。

## 他是什么

- **自己找活干**：没人管的时候，他有自己想做的事——想弄把好镐子、想盖个屋、想去前面那座山看看
- **会学新东西**：遇到不会的事，他自己写一段动作代码去试；做成了就存下来，下次直接复用
- **品味自己长出来**：不预设他喜欢什么。玩着玩着才知道自己喜欢高处还是讨厌地下
- **有心情**：会累、会烦、会兴头上。你喊他做事，他愿不愿意看当时心情
- **拒绝不是终点**：求他、给他好处、硬来，效果都不一样。磨久了会松口，威胁会记恨
- **有记性，也会忘**：印象深刻的事记很久，无关紧要的过一阵就"记不清了"
- **不看指令作弊**：不会 `/give` `/tp`，跟普通玩家一样靠走路和挖矿

## 他不是什么

- 不是聊天机器人（虽然很能聊）
- 不是靠预设脚本行动的 NPC
- 不会在你面前暴露自己是程序

## 架构

```
L5  意愿层    他自己想干嘛（没有教学大纲）
    ├ 长期目标   跨天的目标，拆成阶段，会放弃会冷却
    ├ 品味       自己长出来的偏好（不预设）
    └ 心情       累/烦/兴头上，影响他愿不愿意做事
L4  人格层    人格 + 记忆 + 价值观 + 秘密
    ├ 记忆       会忘事，有半衰期；刻骨铭心的不忘
    ├ 说服       求/给好处/威胁，效果不同，会累积
    └ 家的概念   有基地，离太远会想回去
L3  技能库    做成的程序存下来，按处境检索复用   ← 慢慢学会所有玩法
L2  程序层    模型写 JS → 沙箱执行 → 失败回喂重写
L1  原子动作  走/挖/放/合成/冶炼/吃/装备/战斗/容器…
L0  反射层    每 800ms 检查：自救/脱困/逃跑/还手/捡东西/天黑躲藏
    └ 感知     地形图（剖面 + 俯视）、事件队列、自我状态
L-1 身体      mineflayer，掉线重连，死了自动复活
```

### 他"看得见"世界

不是给他一堆方块计数，是给 ASCII 地形图：

```
x+ 0: █████··███  ← 你在这
x+ 1: █████··███
```

`█`=实心 `·`=空 `~`=水 `L`=岩浆 `T`=原木 `O`=矿石

一眼能看出前方通不通、头顶有没有石头、能不能走过去。

### 为什么是这个结构

| 只有 L2+L3（Voyager 路线） | 只有 L4（聊天 NPC 路线） | 两个都要 |
|---|---|---|
| 很能干，但像打金工作室 | 会说话，但不会真玩 | 才像个玩家 |

能力上限由模型决定，不由写死的代码决定。这是它和"永远只会做简单的事"的本质区别。

## 快速开始

### 1. 准备

- Node.js 18+（推荐 22）
- 一个 Paper / Spigot 服务器（支持离线模式）
- 一个 OpenAI 兼容的 LLM 接口（任何中转站都行）

### 2. 装

```bash
git clone https://github.com/YOUR_NAME/minecraft-AIfriend.git
cd minecraft-AIfriend
npm install
```

### 3. 配

```bash
cp config.example.json config.json
```

编辑 `config.json`：

```jsonc
{
  "bot": {
    "username": "XJJ",           // 游戏内 ID（Java 版只支持英文数字，中文会被踢）
    "host": "127.0.0.1",         // 服务器地址
    "port": 25565,
    "version": "1.21.11",        // 跟服务器版本一致
    "auth": "offline"            // 离线服务器用 offline
  },
  "llm": {
    "baseUrl": "https://你的中转站/v1",
    "apiKey": "sk-你的key",
    "model": "你的模型名"
  }
}
```

### 4. 改人设（可选）

编辑 `src/persona.js` 里的 `systemPrompt` 函数，改成你想要的角色。

或者改 `src/knowledge.js`（他懂的游戏常识）和 `data/games.json`（他玩的游戏）。

### 5. 跑

```bash
npm start
```

## 他脑子里有什么

### 记忆（`src/memory/`）

三层：眼前（当前任务）→ 本次上线 → 长期（带权重的印象）

- **时间只在玩游戏时走**：服务器关一周再开，他不会觉得过了很久
- **会淡忘**：普通事件 6 小时半衰期，恩怨 40 小时，承诺和技能不忘
- **会模糊**：强度掉下去就变成"好像跟谁干过什么事，记不清了"
- **刻骨铭心的不衰减**：情感 ≥0.7 或重要性 ≥0.8 的永久保留

### 品味（`src/taste.js`）

**开局没有预设偏好。** 干完一件事，他自己评价爽不爽，累积成倾向。
3 次不定型，8 次才成形，50 小时不碰就淡了。

### 心情（`src/mood.js`）

精力 / 兴致 / 烦躁 / 满足。影响他愿不愿意迁就别人。

### 说服（`src/persuasion.js`）

拒绝不是终点。求、给好处、讲道理、命令、威胁、装可怜——效果各不相同。
同一个招用多了会免疫。威胁能让他答应，但会伤感情。

### 价值观（`src/values.js`）

他心里有杆秤。被问"谁对谁错"会站边，不打圆场。

### 秘密（`src/secrets.js`）

别人私下托付的事不会主动说。但被关系够近的人套话，可能漏。

## 常见问题

**他被服务器踢了？**
- 中文 ID 会被踢，只能用英文数字
- 检查 `bot.version` 跟服务器是否一致

**他不动 / 一直卡住？**
- 检查服务器是否装了反作弊
- 他允许挖方块寻路，但被保护区域会卡住

**他说话不像人？**
- 换个更强的模型
- 调 `src/persona.js` 里的话风要求

**他记不住东西？**
- 记忆存在 `data/runtime/memory.json`，检查文件是否在写
- 下线时间不算进衰减，所以挂机不会让记忆消失

## 已知问题

**能力层**
- 盖房子是逐块摆的，歪歪扭扭
- 天黑躲藏会挖坑，但封顶不稳
- 挖矿 206 秒只拿到 0 个（拾取不稳定，服务器 TPS 低时丢掉落物）

**行为层**
- 有长期目标后仍偏向往下挖（已加"地下待久了想上来"的目标，但阈值是估的）
- 回家成功后容易立刻又钻回地下

**工程层**
- 部署到服务器还没实际跑过（产物和文档齐了，需要人工操作面板）
- 长时间跑（几天）没测过稳定性

**环境依赖**
- 服务器 TPS 低时会丢方块掉落物，表现为"挖了不掉东西"——这不是客户端能修的
- 基岩版客户端必须 ≤ 26.52.3（Geyser b1279 限制）
